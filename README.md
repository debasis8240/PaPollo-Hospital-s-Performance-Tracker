# 🏥 Papollo Healthcare Dashboard | Power BI

A comprehensive **Healthcare Analytics Dashboard** built using **Power BI** to analyze hospital operations, patient admissions, diagnosis trends, billing, insurance coverage, doctor performance, and patient satisfaction.

## 📌 Project Overview

This interactive Power BI dashboard transforms healthcare data into actionable insights, enabling hospital administrators and healthcare professionals to monitor operational performance, optimize resource allocation, and improve patient care.

The dashboard provides analysis on:

- 📊 Patient Admissions & Discharges
- 🏥 Bed Occupancy
- 🩺 Diagnosis-wise Patient Count
- 👨‍⚕️ Doctor Performance
- 💰 Billing & Insurance Analysis
- 🧪 Medical Test Analysis
- ⭐ Patient Feedback
- 📈 Hospital KPIs

---

## 🚀 Project Objectives

- Monitor patient admission trends.
- Track hospital bed utilization.
- Analyze diagnosis-wise patient distribution.
- Compare billing amount with insurance coverage.
- Evaluate doctor workload.
- Monitor patient feedback.
- Provide interactive business insights for healthcare management.

## 📈 Key Insights

### 🏥 Hospital Performance

- Private wards have the highest occupancy.
- ICU occupancy is comparatively lower.

### 🩺 Diagnosis Analysis

- Viral Infection is the most common diagnosis.
- Fracture cases are the least frequent.

### 💰 Financial Insights

- CT Scan and Ultrasound contribute the highest billing.
- Insurance coverage closely follows billing across all medical tests.

### 👨‍⚕️ Doctor Analysis

- Patient feedback is evenly distributed among doctors.
